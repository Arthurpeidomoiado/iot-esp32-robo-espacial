# iot-esp32-robo-espacial

Nome do projeto: Robo-Espacial
  Objetivo da etapa 1: Fazer um projeto de um robo que se movimenta, no ambiente virtual do wowkiwi.
  Lista dos componentes do circuito: Analógico, Esp32, Led vermelho, Led Verde, Botão.
  Como rodar o programa: Use o código em código no terminal de comandos e depois aperte a seta horizontal para funcionar o circuito.
